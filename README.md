## Описание

CLI-инструмент для визуализации графа зависимостей Maven-пакетов.
Готовые менеджеры пакетов и библиотеки для получения зависимостей **не используются**.

## Установка

    git clone <URL>
    cd DependencyVisualizer
    pip install -r requirements.txt

## Запуск

    # С тестовым репозиторием
    python3 -m src.main \
        --package A \
        --test-repo data/test_repo.txt \
        --test-mode \
        --ascii-tree

    # С реальным Maven-репозиторием
    python3 -m src.main \
        --package org.example:library \
        --repo https://repo.maven.apache.org/maven2 \
        --ascii-tree

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--package`, `-p` | Имя анализируемого пакета (обязательный) |
| `--repo`, `-r` | URL-адрес Maven-репозитория |
| `--test-repo` | Путь к файлу описания тестового репозитория |
| `--test-mode` | Режим работы с тестовым репозиторием |
| `--ascii-tree` | Вывод зависимостей в формате ASCII-дерева |

## Этап 1. Минимальный прототип

Реализовано CLI-приложение с разбором параметров командной строки
и выводом всех параметров в формате ключ-значение.

**Обработка ошибок:**
- Отсутствие обязательного `--package` → ошибка argparse
- `--test-mode` без `--test-repo` → `Ошибка конфигурации`
- `--repo` без `--test-mode` и без `--test-repo` → `Ошибка конфигурации`
- `--test-repo` без `--test-mode` → `Ошибка конфигурации`

### Демонстрация

    $ python3 -m src.main --package A --test-repo data/test_repo.txt --test-mode --ascii-tree
